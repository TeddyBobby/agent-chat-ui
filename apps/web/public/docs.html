PiAgent 当前架构

前后端分离的本地 AI 编程助手。任务生命周期由持久化 API Server 管理，页面刷新只断开订阅，不会取消 Agent。

系统边界

Browser / Electron Renderer
        │ HTTP commands + replayable SSE
        ▼
apps/server
  ├─ RunManager ───────────────► packages/agent
  ├─ CredentialVault                 ├─ streaming LLM
  └─ SQLite/WAL                      └─ local tools
        ▲
        └──── packages/contracts（共享实体与事件）
模块职责
apps/web服务端快照、任务命令、SSE 重连和 React 渲染
apps/serverHTTP API、SQLite、RunManager 和加密凭据
apps/desktop本地静态 Web/API、Electron 窗口和 DMG 打包
packages/agent模型工具循环、上下文压缩和文件/命令工具
packages/contractsConversation、Run、ToolCall 与 RunEvent 协议

可恢复任务流

POST /v1/conversations/:id/runs
  → 202 + Run

GET /v1/runs/:id/events?after=<seq>
  → persisted replay + live SSE

POST /v1/runs/:id/cancel
  → explicit AbortController cancellation

事件先写入 SQLite 并更新读取投影，再发布给实时订阅者。每个事件拥有单调递增的 seq；客户端刷新后从最后游标继续。

数据与凭据

SQLite 保存 conversations、messages、tool_calls、runs、run_events 和 credentials。浏览器只保存界面偏好，不保存 API Key。

API Key 使用 AES-256-GCM 加密。任务请求不携带 Key；运行和连接测试都从服务端 CredentialVault 读取。点击“登出”才删除已保存凭据。

Electron 生产包

  1. Next.js 在桌面构建时静态导出。
  2. esbuild 将 Server、Agent 和 Contracts 打成单文件。
  3. better-sqlite3 针对 Electron ABI 重建。
  4. Web 与 API 只监听 127.0.0.1 的动态端口。
  5. 数据库写入 Electron 的用户数据目录。
  6. 应用保持单实例，桌面 API 只允许当前 Renderer Origin。
pnpm electron      # 本地桌面运行
pnpm package:mac   # release/PiAgent-0.2.0-arm64.dmg

恢复范围

场景结果
刷新页面、关闭窗口订阅、短暂断网后台任务继续，重新连接后重放缺失事件
重复发送启动命令同一 idempotencyKey 返回原 Run
完全退出 Electron / Server运行终止；下次启动标记为 interrupted

安全边界

Server 可以读取、修改本地文件并执行命令，当前定位是单用户、本地优先应用。未经认证不得直接暴露到公网；多用户服务还需要认证、租户隔离、工作区沙箱、SSRF 防护、限流和审计。
